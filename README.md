# orpheus-releases

Выпуски продуктов Орфей для обновлялок. Кода здесь нет, кроме файлов установки в корне.

Каждый выпуск — одна версия одного продукта: метка `<id>-v<версия>`, файлы, `manifest.json` и его подпись
`manifest.json.sig` (ключ `orpheus-release`). Обновлялка ставит выпуск, только если подпись манифеста верна, продукт её,
версия новее стоящей, а размер и SHA-256 файла совпали с манифестом.

Выпуски создаёт только `release/publish.py` из `metodex-tech/workflow`. Устройство системы, формат манифеста и правила —
`workflow/release/README.md`. Выпуски неизменяемые, флаг Latest не ставится: обновлялка выбирает по своей метке.

## Файлы установки

Постоянный адрес установки продукта на чистую машину — `<id>-setup.sh` в корне (`workflow/release/README.md`,
«Файл установки в корне канала»).

| Файл | Что ставит | Команда |
|---|---|---|
| `workstation-setup.sh` | Орфей на чистом Omarchy: Workstation, экраны загрузки и входа, мессенджер, локальный ИИ (`orpheus-omarchy/docs/setup.md`) | `curl -fsSL https://raw.githubusercontent.com/metodex-tech/orpheus-releases/main/workstation-setup.sh \| bash` |

Файл только находит последний выпуск своего продукта и проверяет подпись его манифеста ключом `orpheus-release`.
Остальное делает установщик из проверенного выпуска. Собирает файл `orpheus-omarchy/tools/bake-setup.sh` из профиля
поставки, руками его не правят. Это корень доверия первой установки, поэтому он меняется только через PR, а сливает
PR владелец.
